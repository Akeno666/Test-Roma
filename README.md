# Ромометр

Шуточный тест из семи вопросов. Все ответы обрабатываются только в браузере:
сайт ничего не отправляет и не сохраняет. После прохождения показываются баллы
и просьба отправить Кириллу скриншот результата.

## Публикация на GitHub Pages

1. Загрузите содержимое этой папки в корень репозитория.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source → GitHub Actions**.
4. Откройте вкладку **Actions** и дождитесь завершения процесса
   **Deploy Romometer to GitHub Pages**.
5. Готовая ссылка появится в **Settings → Pages**.

Для GitHub Free репозиторий должен быть публичным. В проекте нет токенов,
паролей, Telegram ID или автоматической отправки результатов.
